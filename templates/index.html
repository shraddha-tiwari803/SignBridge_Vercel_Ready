Prototype limitation

This recognizes a limited set of static hand gestures. It does not translate full sign language or understand facial expressions, body posture, movement sequences, or context.

How to use

1. Select Start camera and allow permission.
2. Show a supported gesture clearly.
3. Read the predicted label, confidence score and caption.

Privacy and processing

For this hosted version, small camera snapshots are sent to the Python endpoint for recognition. The app code does not save them to a database, but the hosting provider processes requests. Stop the camera when finished and avoid sensitive footage.
